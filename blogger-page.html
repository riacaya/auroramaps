📲 Di Android

  1. Tanpa APK: buka aplikasi web di Chrome → menu (⋮) → Install app / Tambahkan ke layar utama.
  2. Dengan APK: unduh file di atas, buka file-nya, izinkan pemasangan dari sumber tidak dikenal bila diminta.

APK hanyalah cangkang: seluruh isi aplikasi dimuat dari GitHub Pages, jadi perubahan situs langsung terbawa tanpa build ulang.

🖥️ Di Windows (sidecar)

  1. Dobel-klik Pasang-Sidecar.exe → klik Install.
  2. Tunggu 100%, lalu OK — pemasang tertutup sendiri.
  3. Sidecar berjalan tersembunyi, hidup otomatis saat login Windows, dan pintasan AuroraMaps muncul di Desktop/menu Mulai.

Windows menampilkan “Windows protected your PC”? Pilih Info lainnya → Jalankan.

Fitur cek bidang, zona, dan analisa membutuhkan sidecar terpasang di komputer itu dan koneksi internet; tanpa sidecar, peta & layer tetap bisa dipakai. Login diperlukan saat pertama kali membuka aplikasi.
